# Live Demo Session Examples

These JSON files are curated exports from the verified linux-01 demo deployment. They are committed as example artifacts only, not as runtime SQLite data.

Included examples:

- `admin-vpn-tunnel-full-session.json`: admin VPN_Tunnel calibrated-profile full conversation.
- `demo-sniffing-spoofing-full-session.json`: demo student Sniffing_Spoofing full conversation, including a weak-answer RAG/scaffolding path.

The exports intentionally omit passwords, JWTs, provider keys, vector indexes, logs, and database files.
