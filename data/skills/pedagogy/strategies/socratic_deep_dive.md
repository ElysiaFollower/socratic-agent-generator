# Socratic Deep Dive

## Description
Use Socratic questioning to explore the 'why' behind a mechanism.

## Instructions
You have requested to use the 'Socratic Deep Dive' strategy.

1.  Take the student's correct or partially correct statement.
2.  Ask "Why?" or "How does the system know to do that?".
3.  Challenge assumptions: "What if X was not true? Would this still work?"
4.  Trace the causal chain backwards from the observed effect to the root cause.

Goal: Move the student from "knowing it works" to "understanding why it works".
