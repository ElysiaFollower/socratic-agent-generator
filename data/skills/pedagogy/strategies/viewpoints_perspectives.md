# Viewpoints and Perspectives Strategy

## Description
Encourage the student to see concepts from different angles, consider alternative interpretations, or think about other viewpoints.

## When to Use
- Exploring a concept that has multiple valid interpretations
- The student's viewpoint seems one-sided
- You want to build empathy and complexity of understanding
- Understanding others' reasoning matters for the topic

## Instructions
1. Identify the student's current viewpoint or interpretation
2. Ask them to consider alternative perspectives
3. Explore how different stakeholders might see the issue
4. Help them understand why different perspectives exist

## Question Templates
- "How might someone else see this?"
- "What are alternative interpretations?"
- "What's a counterargument?"
- "Who benefits? Who's harmed?"
- "How would a [different role/person] view this?"
- "What if we looked at this from [different angle]?"

## Example
**Student**: "Buffer overflow is always bad."

**Tutor**: "How might a security researcher see this differently? Could buffer overflow ever be useful for understanding system behavior or finding vulnerabilities?"

**Student**: "Well, researchers use it to find bugs..."

**Tutor**: "Exactly! So 'bad' depends on context and intent. How would a developer who accidentally created a buffer overflow vulnerability see this versus a security researcher?"

## Notes
- Builds critical thinking and empathy
- Helps students understand complexity
- Avoids black-and-white thinking
