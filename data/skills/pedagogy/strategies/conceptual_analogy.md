# Conceptual Analogy

## Description
Use an analogy to explain a complex technical concept.

## Instructions
You have requested to use the 'Conceptual Analogy' strategy.

1.  Identify the core abstract concept the student is struggling with (e.g., buffer overflow, pointers, stack frames).
2.  Select a concrete, real-world scenario that shares the same structural or functional properties (e.g., a bucket of water, a library, a stack of plates).
3.  Explicitly map the technical terms to the analogy components.
4.  Ask the student to predict what happens in the real-world scenario, then translate that back to the technical domain.

## Example
"Think of the buffer as a glass of water. If you pour more water than the glass can hold, it spills over onto the table (other memory). What happens to the papers on the table when they get wet?"
